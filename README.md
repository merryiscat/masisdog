# masisdog

**에이전트-퍼스트 폰** — 온디바이스 LLM 에이전트가 안드로이드 폰의 관리자로 상주하며,
저장공간·네트워크·알림·화면을 관장하고 스스로 권한을 수리하며 생존한다. 개인용.

## 지금 어디까지 정해졌나

- **경로**: 커스텀 OS를 올리는 게 아니라 **순정 안드로이드 위 앱 계층**으로 시작한다.
  (갤럭시는 One UI 8부터 부트로더 언락이 막혀 커스텀 OS 불가 → 앱 계층이 현실적 시작점)
- **1단계 (현재)**: PC에서 폰을 원격 조작하며 "LLM이 폰을 조작한다"는 개념을 검증한다.
  `mobile-mcp` / `uiautomator2` / `adb`.
- **2단계**: 검증된 조작 로직을 온디바이스 앱(Accessibility Service 기반)으로 이식한다.

자세한 배경·결정·기술 스택·능력의 천장은 [`docs/plan.md`](docs/plan.md) 참조.

## 구조

```
masisdog/
├─ docs/          기획·결정 기록 (단일 출처)
```
